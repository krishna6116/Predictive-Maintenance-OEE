## Conclusions

1. Feature engineering is the largest real gain: the same Ridge model goes from 20.59 to 16.28 RMSE.
2. Age alone (31.20) beats the fleet average (41.94) but is far behind any sensor model.
3. Over all test engines, XGBoost and Ridge on the same features are statistically tied; near failure, XGBoost is clearly better on validation and on test, so it is the published baseline.
4. Removing FFT, EMA, or s9 and s14 has no measurable effect; the features are kept and this is stated.
5. **Bar for Phase 5:** beat 15.08 RMSE and 565 PHM08 with a paired, Holm-corrected interval that excludes 0, and stay at least as accurate near failure.
