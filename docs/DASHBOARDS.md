## What building the dashboards found

- **Monte Carlo noise in the intervals.** The first export read the fleet page from `public.fact_prediction`, whose last-cycle rows are Phase 6's *rolling* forecasts: same model, but a fresh set of dropout passes. Against the published forecasts the plan acted on, their MC mean differs by up to 2.54 cycles and 1 engine would change its flag. The spec was corrected in its own commit before any app code, and the About page now shows this noise instead of hiding it.
- **A check that could not fail.** The palette check skipped colours inside chart scales; a test that plants a non-palette colour caught it.
- **Windows path limit.** A clean install under a long folder path silently dropped Streamlit; the app's requirements were re-frozen from a complete install.

## Power BI walkthrough

1. **Load** (Import mode, read-only login `powerbi_ro` from `python -m dashboards.create_readonly_role`): `public.fact_oee`, `public.fact_alert`, `public.fact_prediction`, the three `fact_model_health` tables (`ops`, `ops7b_fresh_synchronized`, `ops7b_fresh_staggered`), and the snapshots `fleet.csv` and `monitoring_runs.csv`.
2. **Shape** in Power Query: add a `Scenario` column to each health table and append them into `fact_model_health_all`; build `dim_engine` from `fleet` (dataset, engine_id, EngineKey = dataset-engine_id) and add `EngineKey` to `fleet`, `fact_alert`, `fact_oee` (machine_id) and `fact_prediction`.
3. **Model** (star schema): `dim_engine[EngineKey]` one-to-many to `fleet`, `fact_alert`, `fact_oee`, `fact_prediction`; a calculated table `dim_shift = GENERATESERIES(1, MAX(fact_model_health_all[shift]), 1)` one-to-many to `fact_model_health_all[shift]`; `dim_dataset` (distinct datasets) one-to-many to `dim_engine` and `fact_model_health_all`.
4. **Measures** (the verifier recomputes every one of them independently):

```DAX
OEE (simulated) =
VAR run_h = SUM ( fact_oee[run_hours] )
VAR planned_h = SUM ( fact_oee[planned_hours] )
VAR ideal_u = SUM ( fact_oee[ideal_units] )
VAR actual_u = SUM ( fact_oee[actual_units] )
VAR good_u = SUM ( fact_oee[good_units] )
RETURN DIVIDE ( run_h, planned_h ) * DIVIDE ( actual_u, ideal_u ) * DIVIDE ( good_u, actual_u )

Unplanned failures = CALCULATE ( COUNTROWS ( fact_oee ), fact_oee[event] = "failure" )
Planned services   = CALCULATE ( COUNTROWS ( fact_oee ), fact_oee[event] = "service" )

Engines = DISTINCTCOUNT ( fleet[EngineKey] )
Flagged = COUNTROWS ( FILTER ( fleet, fleet[rul_low] <= 20 ) )
Interval coverage =
DIVIDE (
    COUNTROWS ( FILTER ( fleet, fleet[true_rul_capped] >= fleet[rul_low] && fleet[true_rul_capped] <= fleet[rul_high] ) ),
    COUNTROWS ( fleet )
)

Engines flagged    = CALCULATE ( COUNTROWS ( fact_alert ), fact_alert[context] = "snapshot" )
Scheduled          = CALCULATE ( COUNTROWS ( fact_alert ), fact_alert[context] = "snapshot", NOT ISBLANK ( fact_alert[scheduled_day] ) )
No crew in horizon = CALCULATE ( COUNTROWS ( fact_alert ), fact_alert[context] = "snapshot",
                                 fact_alert[status] = "flagged, no crew in horizon" )

Runs         = COUNTROWS ( fact_model_health_all )
Flagged runs = CALCULATE ( COUNTROWS ( fact_model_health_all ), fact_model_health_all[needs_retraining] = TRUE () )
Flag rate    = DIVIDE ( [Flagged runs], [Runs] )

Phase 7 drift false-alarm rate =
DIVIDE (
    CALCULATE ( COUNTROWS ( monitoring_runs ), monitoring_runs[scenario] = "phase7_v1",
                monitoring_runs[drift_tested] = TRUE (), monitoring_runs[any_drifted] = TRUE () ),
    CALCULATE ( COUNTROWS ( monitoring_runs ), monitoring_runs[scenario] = "phase7_v1", monitoring_runs[drift_tested] = TRUE () )
)
```

5. **Pages**: the same four questions as the app, each with one table visual whose export the verifier checks (`dashboards/powerbi_checks.py`): `fleet_summary`, `plan_summary`, `oee_policies`, `monitoring_summary`.
